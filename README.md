# lilvim

## Installation
```bash
rm -rf ~/.config/nvim
rm -rf ~/.local/state/nvim
rm -rf ~/.local/share/nvim

git clone https://github.com/christopherbalut/lilvim ~/.config/nvim && nvim
```

## Requirements

Required for Telescope:

- **ripgrep** (`rg`)

Optional (recommended):
```
- **fzf**
- **fd**
```
